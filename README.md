# fakao-answer-review

法考主观题「自己答案 vs 参考解析」深度对比分析 Skill。适用于 Claude Code、Codex 等支持 Agent Skills 的 AI 编程助手。

把你的刷题文档和机构解析文档交给 Agent，它会逐问对齐、诊断差异、定位知识漏洞，并输出一份排版精美的 docx 复盘报告。

## 功能特性

- **全科目通用**：刑法、民法、刑诉、民诉、行政法等主观题科目均可使用
- **四类诊断框架**：定性错误 / 层次缺失 / 争议漏答 / 边界提醒，逐问给结构化诊断
- **采分点拆解**：把参考答案拆成最小可给分单位，逐项标记 命中 / 部分 / 未中
- **宽松估分**：给出预估得分区间，帮助定位与满分的差距
- **知识漏洞清单**：每项漏洞含「你的表述 → 正确规则 → 记忆锚点」四段式
- **法条核验（可选增强）**：环境支持元典（yuandian）MCP 时，报告引用的每一条法条号都会逐条核验原文；缺失时自动降级并明确提示
- **固定美化版式**：脚本固化的 docx 排版——估分表、逐问对比表、法条全文、复盘计划表，开箱即用

## 报告包含

1. 总体诊断 + 估分表
2. 逐问精细对比（考点定位 / 你的答案 / 参考答案 / 差异诊断 / 采分点表）
3. 案件涉及法条全文（法条定位练习）
4. 知识漏洞清单（按优先级排序）
5. 答题技巧提炼
6. 针对性复盘计划（星标优先级）

## 仓库结构

```
fakao-answer-review/
├── SKILL.md                     # Skill 主文件（Agent 读取的工作流程与规则）
├── methodology.md               # 四类诊断方法论与分科目高频陷阱
├── scripts/
│   ├── extract_docx.py          # 提取 docx 段落与表格文本
│   └── render_report.js         # 将 analysis.json 渲染为美化 docx 报告
└── examples/
    └── analysis.sample.json     # 完整分析数据实例（刑法学例）
```

## 环境要求

| 依赖 | 用途 | 必需性 | 缺失时 |
|---|---|---|---|
| Python 3 + python-docx | 提取 docx 文本 | 必需 | `pip install python-docx` |
| Node.js + 全局 docx 包 | 渲染报告 | 必需 | `npm i -g docx` |
| 元典（yuandian）MCP | 法条逐条核验 | 可选增强 | 跳过核验，按严谨性红线执行并提示 |
| LibreOffice + poppler | PDF 目检版式 | 可选 | 仅做 python-docx 结构校验 |

## 安装

将整个目录复制到你的 Agent 的 skills 目录即可，例如 Claude Code：

```
~/.claude/skills/fakao-answer-review/
```

Skill 本体不绑定任何机器或路径，直接复制即可移植。

## 使用

准备好两个 docx 文档后，直接用自然语言触发：

> "文件夹里有柏浪涛10题的刷题版和解析版，帮我分析第二题。"

- **刷题版**：题目 + 你自己手写的答案（文件名常含"刷题""我的答案"等）
- **解析版**：题目 + 参考答案（文件名常含"解析""详解"等）

Agent 会自动完成：提取文本 → 逐问对齐 → 四类诊断 → 生成 analysis.json →（可选）法条核验 → 渲染 docx 报告 → 校验交付。

> 注意：只有题目、没有自己的答案时无法对比——Skill 会拒绝"代写答案再对比"，因为那失去复盘意义。

## 示例

[examples/analysis.sample.json](examples/analysis.sample.json) 是一份完整的分析数据实例（刑法金某系列案，36 分制估得 17.5～19.5 分），可用它直接体验报告渲染：

```bash
export NODE_PATH=$(npm root -g)   # Git Bash；cmd 用 set NODE_PATH=...
node scripts/render_report.js examples/analysis.sample.json 示例报告.docx
```

## 设计原则

- **核心法律分析由 Agent 完成，文档版式由脚本固化**——判断交给模型，排版交给代码
- **严谨性红线**：罪名、法条号必须与参考答案一致；未经核验的条文号禁止出现在报告中；区分"你的表述 / 参考答案观点 / 多数说"三个声音
- **对事不对人**：报告用"你的答案 / 参考答案"指称，错误处给出可直接背诵的正确表述

## 免责声明

- 估分为按采分点宽松估算的参考区间，**非精确评分**，不代表真实阅卷结果
- 法条内容请以官方公布文本为准；未接入法条核验时，报告中条文号仅供参考
- 本工具用于学习复盘，不构成法律意见
